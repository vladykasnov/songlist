# Резервный сонглист Kosmos Lada

Основная витрина: <https://sl.ngoro.dedyn.io/t/kosmos_lada>.

Старый адрес <https://vladykasnov.github.io/songlist/> предлагает зрителю
открыть новую витрину по кнопке. Автоматического перехода нет: браузер должен
давать вернуться назад к резервному каталогу. Его также можно открыть напрямую:
<https://vladykasnov.github.io/songlist/?backup=1>. На резервной странице нельзя
заказать песню — доступны только список и поиск.

`catalog-snapshot.json` содержит последний опубликованный снимок **только
публичных** песен и тегов. GitHub Actions обновляет его ежедневно из
`/t/kosmos_lada/catalog-snapshot.json` на основном сайте. Если отдельный
экспорт ещё не развернут, скрипт умеет брать публичные данные самой витрины.
При ошибке загрузки старый файл остаётся без изменений. `songs.csv` обновляется
одновременно в сокращённом публичном формате для совместимости; внутренние
поля в него не попадают.

Для ручного обновления: `npm ci` и затем `./update.sh` или
`node scripts/update-snapshot.mjs` с последующим коммитом и пушем.
